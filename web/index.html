template

the whole band

Everyone plays in this key, scale and tempo, so it all fits together. “Ignore repeat presses” helps if a switch gets pressed twice by accident, for example with a tremor; it applies to every switch. With “Follow MIDI clock”, if your DAW sends clock to the board’s first MIDI port, sequences and wobbles play at the DAW’s tempo.

musicians

For each musician: 1. add a device, such as notes or a sequencer, 2. choose the switch for each of its jobs (or press press a switch and then the switch), 3. play, and change its notes or shape. Each musician plays on their own MIDI channel, so a DAW can give each one their own sound.

analog inputs

For the Logitech variable triggers, expression pedals and other variable sensors. Each sends a MIDI controller (CC) as it moves. The range starts set for the Logitech triggers. For anything else, use Set range so it covers the whole bar, and Invert if it moves the wrong way. The range belongs to the board, so it applies to every template. Reversed flips an input in this template only. To change a musician’s sound, use the same channel as that musician.

sound in this browser

Turn on with the Sound button at the top. The browser plays everything the board sends, for every musician, in one sound. It responds to vibrato (CC 1), volume (CC 7) and brightness (CC 74). A DAW or synth on the board’s first MIDI port still gets everything as well, on each musician’s channel. Settings here only affect this browser and are not saved to the board.

Notes as

Click a cell to add a note; click a note to remove it; drag it up or down to change it, or drag its right edge to make it longer (when it plays in time). With a keyboard: Tab to a note, then the arrow keys (Shift with left and right for its length) and Delete. The dashed line is the end of the sequence.

A euclidean rhythm spreads the hits as evenly as possible around the steps. Each hit plays the sequence’s next note; the other steps are rests. Changes are heard while it plays.

import a MIDI file

Chords keep their top note, so a sequence plays the melody. Note lengths are kept when it plays in time.
