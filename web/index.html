Edit with

Preset

Changes play on the board straight away and are saved to the preset a moment later. The board remembers its last preset when unplugged.

Key and scale

Switches set to a scale note follow the key and scale: change them here and every switch moves with it.

Sequences and arpeggios

Make up to four. Then choose a switch below and set it to play, step through or restart one.

A euclidean rhythm spreads the hits as evenly as possible around the steps. Each hit plays the sequence’s next note; the other steps are rests. Changes are heard while it plays.

Modulation

Up to four things that move a controller, pitch bend or pressure by themselves: an LFO goes up and down over and over; an envelope rises and falls once each time it’s started. Then set a switch to run one.

Blocks

Drag blocks out of the categories on the left. Each “when …” block runs the blocks inside it, from the top. The name, key and tempo are in the “Preset settings” block. Changes play on the board straight away. With a keyboard: Tab into the blocks area, then use the arrow keys and Enter.

    Analog inputs

    For the Logitech variable triggers, expression pedals and other variable sensors. Each sends a MIDI controller (CC) as it moves. The range starts set for the Logitech triggers. For anything else, use Set range so it covers the whole bar, and Invert if it moves the wrong way. The range belongs to the board, so it applies to every preset. Reversed flips an input in this preset only.

    Settings

    “Ignore repeat presses” helps if a switch gets pressed twice by accident, for example with a tremor. With “Follow MIDI clock”, if your DAW sends clock to the board’s first MIDI port, sequences and LFOs play at the DAW’s tempo and start with it; when the clock stops, the board goes back to its own tempo.

    Sound in this browser

    Turn on with the Sound button at the top. The browser plays everything the board sends, including sequences. It responds to vibrato (CC 1), volume (CC 7) and brightness (CC 74): set an analog input to one of these to hear it move. A DAW or synth on the board’s first MIDI port still gets everything as well. Settings here only affect this browser and are not saved to the board.
